# Support

Thanks for using Git Diff Report.

## Before opening an issue

1. Update to the latest version of the extension (`Extensions` view → check for updates).
2. Check the [Q&A section of the README](https://github.com/Lead007/vscode-diff2html-report#qa) — garbled encoding, empty symbol lists and missing revisions are all covered there.
3. Search [existing issues](https://github.com/Lead007/vscode-diff2html-report/issues) — someone may have hit the same problem.

## Opening an issue

Please use the issue templates. A useful report includes:

- Extension version (shown in the Extensions view)
- VS Code version and OS
- The Git command you ran for the failing report (base revision, current revision, diff options). Open **View → Output**, select the `diff2html-report` channel, and copy the relevant log instead of typing the command from memory.
- What you expected vs. what happened
- A screenshot of the preview if the problem is visual

**Do not paste proprietary source code.** A minimal reproduction repo or a synthetic diff that shows the same problem is far more useful.

## Questions and ideas

Use [Discussions](https://github.com/Lead007/vscode-diff2html-report/discussions) for usage questions, workflow ideas and "would this work for X?" — issues are reserved for bugs and concrete feature requests.

## Security issues

Please do not open a public issue. See [SECURITY.md](SECURITY.md).

## Response time

This is a side project maintained in spare time. Expect a few days before a reply; well-scoped
reports with a reproduction get answered first.
